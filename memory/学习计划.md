# Level-2 微观结构学习计划

> 本金万元级，非盈利导向，以认知积累为目标

---

## 总目标

把 InstOrderTrace 项目积累的数据管线转化为金融微观结构的实战理解力。三层递进：

```
底层：数据敏感度 — 看逐笔数据能直觉判断"这里不对劲"
中层：策略思维 — 能把直觉转化为可回测的规则
顶层：市场理解 — 知道什么策略在什么环境下有效/无效
```

---

## 第一阶段：读懂数据（2周）

目标：对每个特征形成直觉，知道它在描述什么画面。

### 任务 1.1：逐笔数据阅读理解

- 选 1 只股票 × 1 天，打开原始 CSV（逐笔委托/逐笔成交/行情）
- 逐条看，人工标注每笔数据的归属：
  - "游资在吃货？还是散户在跟风？"
  - "这是拆单还是自然成交？"
  - "撤单是试盘还是撤谎钩？"
- 然后看特征引擎算出来的数字是否匹配你的判断

**产出**：[notebook] 一只股票一天的逐笔阅读笔记

### 任务 1.2：特征对照表

- 跑 `compute_features.py` 输出特征
- 对照 `feature_reference.md`，逐特征确认它对应原始数据中的什么行为
- 挑 10 只特征极端的股票，去原始数据验证是否一致

**产出**：[notebook] 特征与原始数据的对照验证

### 任务 1.3：沪深差异实地勘测

- 各挑 10 只 SZ / SH 股票
- 对比 cr, cic, sm 等关键特征的分布差异
- 总结：哪些特征不能跨市场用

**产出**：[文档] SZ vs SH 特征差异备忘

## 第二阶段：手工交易记录（2周起）

目标：用万元本金做实验，记录每一笔交易的完整决策链。

### 实验规则

```
周期：连续 2 周，每周至少 5 笔
标的：ETF（510050/510300）或活跃可转债
规则（示例，后续可调）：
  1. 开盘 30min 内主动买入比 > 0.65
  2. 撤单率 < 0.2（排除试盘）
  3. 成交间隔 CV < 1.5（规律资金流入）
操作：买入 1000 元，当天收盘前平仓
```

### 记录模板

```
日期: 2026-07-08
标的: 510050
信号:
  - 开盘 5min 主动买入比: 0.72 ✓
  - 撤单率: 0.15 ✓
  - 成交间隔 CV: 0.89 ✓
  - OBI: +0.23
入场价: 2.850
出场价: 2.862
盈亏: +12.00 (+0.42%)
决策复盘:
  信号触发强度中等，入场犹豫了一下导致追高，但有信号支撑所以没慌。
  出场时主动卖出比开始上升+OBI转平，及时止盈是对的。
  改进：可以在触发信号的同时设好条件单，减少犹豫时间。
```

**核心目标**：积累 200+ 笔交易记录，形成一套"信号→决策→结果→修正"的闭环资产。

## 第三阶段：从数据到策略（长期）

目标：把直觉总结成规则，把规则落实为代码。

### 项目 A：Level-2 心电图可视化

```
x轴：时间（全天）
y轴：成交价格
气泡大小：每笔成交量
颜色：主动买(红) / 主动卖(绿) / 撤单(灰)
叠加：中间价趋势、累计OBI、每分钟主动买卖比
```

**产出**：一个能让逐笔数据"一眼看清"的可视化工具

### 项目 B：手工标注 100 个交易日画像

- 选 100 只 × 1 天
- 看逐笔数据，人工判断：游资主导 / 量化主导 / 中性
- 记录判断依据（哪个信号最强烈）
- 与特征引擎的结果对比
- 找出分歧的原因

**产出**：[数据集] 100 个标注样本，[文档] 人机判断分歧分析

### 项目 C：订单簿模拟器

- 用真实的逐笔订单流重建订单簿（买10档 / 卖10档）
- 在过程中检测：撤单 → 标记是否为虚假挂单
- 验证：检测到的虚假挂单是否后续伴随价格反转

**产出**：[脚本] 订单簿重建与虚假挂单检测器

## 关键原则

1. **记录比交易重要**。200 笔记录的认知资产 > 账面盈亏
2. **先理解再动手**。一个特征不理解就去看原始数据，不看论文看数据
3. **不做复杂模型**。万元本金 + 规则信号 = 够了。ML 先不用碰
4. **亏 2000 块比花 20000 上课学到的多**。重要的是记录，不是收益
