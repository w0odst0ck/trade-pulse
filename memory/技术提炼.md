# InstOrderTrace 技术提炼 — ETF 模型可复用

## 数据管线架构

```
7z（逐笔委托+逐笔成交+行情）
  → py7zr 流式解压（200只/批，防 OOM）
  → 特征提取（流式，内存 < 1GB）
  → parquet 输出（70~110维）
  → z-score归一化（按标的独立归一化，需 ≥5天数据）
```

**核心脚本：** `tools/level2-toolkit/`

## 特征体系（70+ 维，5 大维度）

| 维度 | 核心特征 | 物理意义 |
|------|---------|---------|
| **OSS** 订单规模 | 委托数、买卖比、成交量中/均值、大/中/小/超大 单占比（分方向） | 谁在交易、交易量级 |
| **RS** 节奏特征 | 到达间隔均值/中位数/CV、爆发比、快速委托比、8时段分布 | 算法vs人工、交易频率 |
| **CB** 撤单行为 | 撤单率、方向、时段分布、间隔 | 真假挂单、试盘行为 |
| **AP** 主动成交 | 主动买卖比、连续买入强度、成交集中度、间隔、分钟强度 | 资金推动意愿 |
| **OBP** 订单簿压力 | 价差均值/标准差、OBI、中间价波动、累计成交额 | 挂单博弈、均衡状态 |

## 关键经验教训

1. **沪深差异极大：** SZ 撤单率 0.4%，SH 撤单率 45.8%—特征要分市场归一化，跨市场混用会崩
2. **拆单破坏日频统计：** 机构拆单后日频信号几乎消失，必须用逐笔级别特征
3. **数据量 ≠ 信号量：** 110 维特征经跨日验证 98.86% 可用 30 维核心特征复现，冗余特征只会过拟合
4. **无标签数据上 ML 风险高：** 比赛经验证明规则伪标签会导致严重偏倚（95% 预测游资），规则先行比 ML 更可靠
5. **LightGBM 适用场景：** 只有当你有可信标签（比如人工标注）时再用，否则规则判断更稳健

## 之前识别出的高价值信号雏形

- **OBI 极值 + 价差收窄** → 价格回归信号
- **主动买卖比突破 0.7 + 持续 >3min** → 资金流入确认
- **撤单率突降 + 挂单量上升** → 虚假挂单退场，真方向显现
- **成交间隔 CV < 0.8 + 成交量放大** → 算法资金集中推动
